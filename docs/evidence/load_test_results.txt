### Key Observations & Bottleneck Analysis:
1. **Baseline Ingress (`GET /health`)**: Scales from ~65 RPS at C=1 to over 550 RPS at C=50 with sub-10ms p95 latency. Nginx keepalive connection pools and lightweight Express endpoint perform efficiently.
2. **Auth Endpoint (`POST /api/v1/worker/login`)**: Under C=10 and C=50 bursts, Express `authRateLimiter` (15 req/15min) and Argon2id hashing actively engage. After the initial 15 successes, remaining requests return HTTP 429 Too Many Requests within 1.2ms, protecting backend CPU from brute-force hash exhaustion.
3. **Direct Triage Inference (`POST /api/v1/consultation/triage`)**: Routes synchronously via Express -> FastAPI ML (:8000) Naive Bayes engine. At C=50, throughput maintains ~75-90 RPS with p95 ~35ms, demonstrating non-blocking asynchronous event loop proxying.
4. **Async Queue Path (`POST /analyze/async`)**: Enqueues analysis jobs into MongoDB backed by atomic deduplication. Maintains ~120 RPS at C=50 with 0% server error rate.
