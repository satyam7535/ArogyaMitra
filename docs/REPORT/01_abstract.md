# Chapter 1: Abstract & Executive Summary

## Abstract

In rural India and developing economies, the severe disparity in doctor-to-population ratios (averaging 1:1,511 in rural areas versus the WHO-recommended threshold of 1:1,000) places primary healthcare triage almost entirely upon Community Health Workers (e.g., Accredited Social Health Activists or ASHA workers). However, frontline workers face severe diagnostic challenges due to overlapping symptom presentations, absence of diagnostic laboratory equipment, and lack of specialized clinical training. Furthermore, existing AI diagnostic prototypes frequently exhibit critical technical shortcomings: dataset leakage resulting in inflated evaluation metrics, uncalibrated probability predictions, black-box opaque outputs, vulnerable cleartext patient storage, and monolithic architectures vulnerable to network latency and concurrency bottlenecks.

This project presents **ArogyaMitra** (आरोग्यमित्र), a privacy-first, AI-assisted primary healthcare decision support prototype engineered to bridge this divide. The system combines an empirical machine learning pipeline with a multi-layered microservices architecture:
1. **Mathematical Rigor & Data Hygiene**: We uncovered a 93.8% row duplication rate in commonly used clinical benchmark datasets (4,920 rows containing only 304 unique profiles). We established an un-leaked evaluation baseline using 5x3 Repeated Stratified K-Fold cross-validation and symptom-dropout augmentation.
2. **Calibrated Diagnostics & Explainability**: A LightGBM tree ensemble was tuned via Optuna, calibrated using Sigmoid/Platt Scaling (achieving an Expected Calibration Error of 0.0384 and Brier Score of 0.0121), and coupled with TreeSHAP to provide exact, axiomatic Shapley feature attribution charts.
3. **Defense-in-Depth Security**: Patient Personally Identifiable Information (PII) is encrypted at rest using AES-256-GCM authenticated encryption. User credentials are protected using memory-hard Argon2id hashing with account lockout and rotating refresh tokens. The backend implements multi-tenant organization scoping, returning HTTP 404 on cross-tenant requests to prevent resource enumeration.
4. **Resilient AI Orchestration**: An asynchronous job queue decouples long-running LLM clinical synthesis from the client request loop, maintaining sub-15ms acceptance latency and 0.00% request failure across heavy concurrency tiers. Clinical prompt injection is mitigated via XML isolation, strict Pydantic v2 schemas, and deterministic safety fallbacks.
5. **Human-in-the-Loop Clinical Workstation**: A multilingual (English, Hindi, Marathi) Streamlit interface provides dedicated triage, physician review, and administrative governance portals, generating bilingual PDF diagnostic summaries via ReportLab.

Empirical verification confirms that ArogyaMitra delivers mathematically grounded, transparent, and regulatory-compliant clinical decision support for frontline rural healthcare delivery.
